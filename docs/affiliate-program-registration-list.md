## 特に注意しておきたい点

1. **FXGT**: fxgt.comが実際にはTraders TrustのIBページへ転送される挙動が確認された。ブランド統合の可能性があるため、登録前に必ず現状を直接確認すること。
2. **LAND-FX(Land Prime)**: ロイヤルティプログラムが日本居住者を明示的に対象外としている。基本の継続コミッションとは別枠の話なので、登録前に何が使えて何が使えないか要確認。
3. **Vantage・Windsor Brokers**: パートナーポータルに日本語の選択肢がない。英語でのやり取りが必要になる可能性が高い。
4. **登録しやすさで比較すると**、AXIORY・BigBoss・ThreeTrader・Milton Marketsは日本語対応・情報公開度が比較的高く、着手しやすいと思われる。
