# 業者ロゴの置き場所

このフォルダに `<業者のslug>.svg`（または `.png` / `.webp`）を置くと、
サイト内の業者ロゴ表示が自動的にその画像に切り替わります。
コードを書き換える必要はありません。ファイルを置くだけです。

## ファイル名（slug）の一覧

| ファイル名 | 業者 |
|---|---|
| `xm.svg` | XM(XM Trading) |
| `exness.svg` | Exness |
| `titanfx.svg` | TitanFX（タイタンFX） |
| `hfm.svg` | HFM(HotForex) |
| `bigboss.svg` | BigBoss |
| `fxgt.svg` | FXGT（FXGT.com） |
| `axiory.svg` | AXIORY(アキシオリー) |

拡張子は `.svg` `.png` `.webp` `.jpg` に対応しています。優先順位は svg → png → webp → jpg。

## ロゴの入手先

各社のアフィリエイト／パートナー管理画面にログインし、
「メディアキット」「バナー」「ロゴ」「Marketing Tools」などの名称のページから
公式のロゴ素材をダウンロードしてください。

パートナー向けに配布されている素材を使うのが、規約上もっとも安全です。
公式サイトから画像を直接保存して使う場合は、各社の利用規約・商標ガイドラインを確認してください。

## 推奨仕様

- 背景が透過されているもの（白背景のカード上に置くため）
- 白抜きロゴ（白文字）は白背景で見えなくなるので、濃い色版を選ぶ
- 横長のロゴを想定。高さ 40px 相当で表示されます
- SVG があれば SVG を優先（拡大しても劣化しないため）
